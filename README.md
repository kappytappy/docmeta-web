# DocMeta Web

View and carefully edit PDF and Word (.docx) document metadata — author,
last modified by, creation and modification dates, title, subject, keywords.

Single downloadable Windows exe, no Python or ExifTool install needed.
Built with PyInstaller on GitHub Actions; ExifTool is bundled for PDF
handling, python-docx handles Word documents.

Download `docmeta-web.exe` from the
[Releases page](https://github.com/kappytappy/docmeta-web/releases),
double-click it, your browser opens automatically.
